# Station 24 – Richman

**Xonix Modifications**  
*Release Date: 2025-06-23*

A custom MLO interior and exterior for the Richman Station, created for use in **FiveM**.

---

## Installation (FiveM)

1. **Unzip** the folder `Station24`.
2. **Drag** the `station24` (resource) subfolder into your server's resource directory:
3. **Add to your `server.cfg`**:

```yaml
ensure station24
```
