installation manual:

1. After downloading the resource, unzip the file and put it in your maps folder on the server
2. Go to your server config
3. Add the interior to the config * ensure (map folder name)
4. After completing these steps, turn on the server and enjoy your interior

IMPORTANT!!!

- Each interior is optimized for your FPS
- Before uploading the interior, check the location to see if the interiors will overlap
- In case of errors or problems with uploading the interior, open a ticket on my discord server. You will receive an answer within 24 hours
- Requests to move interiors to other maps such as libetry city etc. will be rejected!
- Recommended server build 3258
